# Blackjack Simulator

A browser-based blackjack simulator built with HTML, CSS, and JavaScript.

## Features

- Manual, Auto, and Fast simulation modes
- Machine and real shoe gameplay
- Running Hi-Lo card count
- Multiple betting systems
  - Martingale
  - Flat Betting
  - Custom Bet
- Selectable blackjack payouts
  - 3:2
  - 6:5
  - 2:1
- Bankroll tracking and profit graph
- Basic strategy trainer with feedback
- Keyboard shortcuts
- Insurance and pair splitting (table mode)

## Running

Simply open `simple_blackjack_sim.html` in any modern web browser.

Or visit the GitHub Pages deployment once enabled.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
